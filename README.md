# 🏡 가족 공동 별장 예약 관리 서비스

가족이나 외가 친척들이 같이 쓰는 별장을  
좀 덜 불편하게 쓰려고 만든 프로젝트입니다.

카톡이나 전화로 “나 이번 주 써도 돼?” 이런 식으로 맞추다 보니까  
겹치거나 헷갈리는 경우가 생각보다 많아서,  
그걸 조금 정리해보고 싶어서 시작했습니다.

---

## 📌 프로젝트 한 줄 요약

> 초대코드 + 관리자 승인 기반으로 운영되는 폐쇄형 별장 예약 서비스

---

## 🤔 왜 만들었나

실제로 가족끼리 별장 쓰다 보면 이런 문제들이 있었습니다.

- 누가 언제 쓰는지 한눈에 안 보임
- 일정이 겹쳤을 때 기준이 애매함
- 가족 외 인원이 섞일 수 있음
- 관리자 입장에서 통제가 어려움

그래서 단순 예약 기능이 아니라,

- 아무나 접근하지 못하고
- 승인된 사용자만 이용하고
- 예약은 명확하게 관리되는

형태로 만들어보는 것을 목표로 했습니다.

---

## ⚙️ 주요 기능

### 👤 회원 / 인증

- 초대코드 기반 회원가입
- 가입 시 `PENDING` 상태로 저장
- 관리자 승인 후 `ACTIVE` 상태에서만 로그인 가능
- JWT 기반 인증

---

### 🎟 초대코드

- 1회용 코드
- 상태 관리
  - `ACTIVE`
  - `USED`
  - `EXPIRED`
  - `REVOKED`
- 만료된 코드는 사용 시 자동으로 `EXPIRED` 처리

---

### 📅 예약 (진행 중)

- 날짜 단위 예약
- 시작일 ~ 종료일 포함
- 하루 단위 예약 가능
- 예약 취소 기능
- 관리자 예약 수정 기능 예정
- 캘린더 기반 조회 예정

---

## 📏 정책 정리

### 회원가입

- 초대코드 없으면 가입 불가
- `signupNote`는 선택 입력
- 가입 후 바로 사용 불가
- 관리자 승인 후 이용 가능

---

### 로그인

- `ACTIVE` 상태만 로그인 가능
- `PENDING`, `REJECTED`는 로그인 차단
- 아이디 존재 여부는 구체적으로 노출하지 않음 (보안)

---

### 예약 중복 기준

기존 예약: A ~ B
신규 예약: X ~ Y

A <= Y && B >= X

하루라도 겹치면 중복으로 처리합니다.

## 🐛 트러블슈팅

### 1. 만료된 초대코드 상태 불일치 문제

#### 문제

만료된 초대코드로 회원가입 시도 시  
가입은 실패하지만 DB에는 `ACTIVE`로 남아있던 문제 발생

#### 원인

같은 트랜잭션 안에서

- 상태 변경
- 예외 발생

→ 전체 롤백되면서 상태 변경도 취소됨

#### 해결

- 초대코드 상태 변경 로직을 `REQUIRES_NEW` 트랜잭션으로 분리

#### 결과

- 회원가입은 실패
- 초대코드는 정상적으로 `EXPIRED` 반영

---

### 2. VSCode PowerShell 한글 깨짐

#### 문제

터미널에서 한글 로그가 깨짐

#### 해결

- UTF-8 인코딩 설정
- JVM / Gradle / PowerShell 설정 통일

#### 결과

정상 출력
